# Tonari 原生版排期

用 Swift / SwiftUI 重写 Tonari，功能与 Flutter 版对齐后替换 Flutter 版日常使用。

- 起点：2026-09-28
- 预计切换：2026-12-11（缓冲一周，最晚 12/18）
- 估算依据：Flutter 版 2026-05～06 的开发节奏；Flutter 版现状约 2.6 万行手写 Dart、14 张表、约 30 个页面，`ios/Runner/AppDelegate.swift` 已有约 1080 行原生代码（bookmark、PiP、NowPlaying 等）可直接复用。

## 1. 技术决策（2026-09-24 已确认）

| # | 决策 | 推荐 | 理由 |
|---|---|---|---|
| 1 | 最低系统 | iOS 26（2026-09-24 由 17 上调） | 自用不上架、设备为 iOS 27；用原生 `tabViewBottomAccessory` 播放栏、`tabBarMinimizeBehavior` 等 iOS 26 API，不写兼容代码 |
| 2 | UI 框架 | SwiftUI 为主，UIKit 补位 | 播放器 PiP、DocumentPicker、横屏视频需要 UIKit |
| 3 | UI 风格 | 暂用系统白色主题 + 底部 Tab（2026-09-24 改定） | 用户决定不沿用 Kikoeru 配色与侧边抽屉 |
| 4 | 数据库 | GRDB | 能直接打开 Drift 生成的 SQLite，表结构原样沿用；SwiftData 需要重新建模且读不了旧库；SQLite.swift 维护活跃度不如 GRDB |
| 5 | 数据迁移 | 实现「从 Flutter 备份恢复」 | 备份/恢复本来就要移植，兼容现有备份格式一份代码两用；恢复后只需重选本地文件夹 |
| 6 | 仓库 | 同仓库 `native/` 目录 | Flutter 代码随时对照、`test/fixtures` 复用；切换后删除 Flutter 部分 |
| 7 | 工程组织 | Xcode 工程（同步文件夹）+ 本地 SPM 包 `TonariCore` | 纯逻辑（解析、扫描、字幕、DLsite）放 SPM 包，`swift test` 快；`.pbxproj` 基本不改 |
| 8 | M7 隐私 | 切换之后再做 | 应用锁、备选图标 Flutter 版没做，不拖慢对齐进度；后台模糊 Flutter 版已有，随 N6 移植 |

第三方依赖控制在 3 个：GRDB、SwiftSoup（HTML 解析）、视频播放器（N0 验证后确定）。网络用 URLSession async/await，Keychain 直接用 Security 框架，WebDAV 继续自写 PROPFIND。

开发期间 Flutter 版冻结：只修 bug，不加新功能。

- 免费证书每台设备最多同时装 3 个 App；Flutter 调试版 + 原生调试版共 2 个，正式版走付费证书不计入。
- 2026-09-25 换新证书后正式版 Bundle ID 变了，原生正式版与 Flutter 正式版并存，不再覆盖安装：N7 在 Flutter 正式版导出备份，原生正式版恢复，确认无误后删除 Flutter 正式版。

## 4. 阶段记录

- **N0（2026-09-24）**：视频选定 mdk-sdk 0.38（C API + 自写 Swift 封装 `MDKPlayer`；官方 swift-mdk 含编辑器占位符编不过）。真机验证 HEVC 10-bit / H.264 10-bit MKV、H.264 MP4 均走 VT 硬解，拖动约 200ms，带 Cookie / Referer / UA 直链与 2 连接上限正常，后台与锁屏控制正常，缺请求头被拒时正确报失败。GRDB 只读打开 Flutter 备份库（schema 16，219 部作品）全部解码。诊断日志提前移植。签名：`ios-resign` 可签原生 .app（含 mdk.framework）。
- **N2（2026-09-24）**：N2a 浏览、N2b 本地导入（单元测试覆盖，真机验证随 115）、N2c DLsite 元数据。修复 SwiftSoup 未做 HTML5 换行规范化；翻译保留改为比较简介内容。
- **N1（2026-09-24）**：14 张表 GRDB Record（`DriftRecord` 统一 Drift 编码约定）、沿用 `user_version`、关闭外键（与 Drift 一致）、Keychain、备份恢复（只接受 schema 17，下次启动应用，跳过 `diagnostic.*`）。真机从 v17 备份恢复：219 部作品、3 个凭据。UI 改为白色主题 + 底部 Tab。
- **N4a（2026-09-24）**：115 扫码登录（TV 二维码）、Cookie 存 Keychain；`P115Client` actor 串行请求、间隔 ≥1.2s、手动跟随重定向合并 Cookie；RSA 加密与 Flutter 测试向量一致。浏览每级文件夹一页（返回逐级后退），记住上次位置（沿用 `browse_stack_p115`）。导入扫描跳过已有作品、下载远程字幕，单作品重扫。设置页导航统一为 value 路由，修复「登录 115」循环跳转。直链播放随 N3。
- **N3a（2026-09-25）**：单个 `AVPlayer` 逐首加载（115 直链按曲解析、带请求头；过期前 2 分钟重取，播放中失败或链接过期后卡住重取一次）。进度 / 收听时长 / 播放历史按 Flutter 口径写库，冷启动按播放历史恢复最后一项（作品或 115 单文件）。锁屏与控制中心、来电打断、AirPods。界面参照 Apple Music：`tabViewBottomAccessory` 迷你播放栏（进度环）、从播放栏缩放展开的全屏深色播放页、自绘粗进度条、字幕 / 队列面板原地替换封面、输出设备图标。修复：Combine `.values` 丢 KVO 变化导致加载卡死，改用缓冲的 `AsyncStream`。N3 拆为 N3a / N3b，播放页字幕从 N3b 提前。
- **N3b（2026-09-25）**：画中画字幕（逐句绘制成帧送入 `AVSampleBufferDisplayLayer`，画中画的播放键控制播放器）；App 内悬浮字幕按用户决定不做。播放历史（音频 / 视频分段、左滑删除、清空）与收听统计（Swift Charts 每日柱状图、作品 / 声优 / 社团前 5 排行榜）。修复：AVKit 在创建画中画控制器时即查询播放状态，启动即崩。

- **界面改版（2026-09-25）**：按第 6 节逐页实现（除 N5 视频）：媒体库三视图、作品详情页（曲目横向翻页、按文件夹组队列、继续播放记位置）、资源页（逐层页面、字幕 / 图片 / 文本预览、115 点开时下载缓存）、浏览页、收藏页、设置页（含存储空间分区清理）、迷你播放栏（字幕句、仿 Apple Music 滑动切歌）、搜索三态。图片预览统一为缩放转场、下拉关闭。播放页字幕放大、控制区空闲自动收起（上滚弹出、下滚收起，浮层不改变字幕区尺寸）、记住上次的面板。修复：详情页进入白屏与卡顿（首帧只渲染封面与标题；简介折叠时不排版全文）。

- **N5（2026-09-25）**：N5a 播放：mdk 引擎 + 外部渲染上下文（MTKView 提供 drawable，主线程调用 `renderVideo`；让 mdk 自管视图时点 / 像素混用，自管图层时渲染线程每帧改 frame 卡死 Core Animation 并被看门狗强杀）；115 直链带头、续播存播放历史、冷启动恢复；音视频互斥由 `NowPlaying` 协调（迷你播放栏、锁屏、睡眠定时跟随前台）；全屏玻璃控件、横滑微调、双击快进退、锁定、旋转（其余页面锁竖屏）；后台暂停 10 分钟释放。N5b 视频库：继续观看、两列 16:9 网格、从「文件」导入（复制到 `videos/<uuid>/`）、115 长按加入、重命名 / 收藏 / 分组 / 移出，播放页 ⋯ 截图设封面（mdk 截图实为 RGBA）、查看所在文件夹，默认视频封面；id 与存放位置沿用 Flutter 版。去掉「从头播放」提示。

- **N6（2026-09-25）**：N6a 消息盒子（`AppEvents`：同类合并计次、保留 200 条；后台任务失败、115 部分作品扫描失败、登录过期、资料补全用尽重试、备份完成写入；设置顶部「消息」行与 Tab 角标）、备份导出（与 Flutter 版同格式，导出后可被任一版恢复；prefs 只带字符串 / 数字 / 布尔 / 字符串列表，最近搜索与曲目目录记忆因此改存 JSON 字符串）、后台模糊（独立最上层窗口，盖住全屏播放页）。N6b 翻译：OpenAI 兼容服务管理（模板、测试连接、默认、删除，Key 存 Keychain），详情页「⋯ → 翻译为中文 / 重新翻译」一次翻标题、简介、曲目名（每批 15 条、条数不符重试 3 次，简介只替换文本节点；SwiftSoup 仅改文本时仍输出原文，改为替换节点）。任务结果改为顶部轻提示条，不再弹确认框。右边缘左滑前进按用户决定不做；文本选中复制系统已支持。

### 作品详情页（2026-09-25，[示意](design/work-detail.html)、[曲目区](design/track-pager.html)）

参照 Apple Music 专辑页 + App Store「信息」区：去掉卡片与灰底块，入口去重（原底部「浏览文件 / 加入分组 / 收藏」三按钮、封面文件印章、顶栏 Safari 按钮全部移除）。从上到下：

1. 顶栏：RJ 号；右侧 ♡ 收藏、⋯（加入分组、在 DLsite 打开、刷新元数据 / 图片 / 统计、重新扫描、移除、显示原文 / 译文）。
2. 封面：主图 + 样图左右滑，点开全屏图集。印章与设置里的「文件入口位置」一并删除。
3. 标题区：标题；声优（主题色，可点 → 声优作品页）；社团 · 发售日 · 语言（社团可点）。
4. 播放：播过显示「继续播放 · 曲名」+ 小字「从头播放」，没播过显示「播放」。继续播放按作品记（`works.last_played_track_id`），与目录选择无关。
5. 曲目：目录菜单「本編 · WAV ⌄」列出所有含音频的文件夹及曲数，默认 `WorkTree.autoPath`，手动选择按作品记住。曲目以 Apple Music「热门歌曲」式横向翻页展示：每列 4 首、下一列露出一截、按列吸附，打开时定位到当前曲所在列。有字幕的曲目带 💬 标记；长按菜单：从这首播放、预览字幕、在文件中显示。下方「全部文件 · N 项」→ 资源页（完整文件树，补上字幕 / 图片 / 文本预览）。
6. 信息：左右两栏行，只列有值的项：评分（星 + 人数）、销量 · 心愿单、排名、价格（折扣）、文件大小 · 格式、类型 · 年龄、翻译自（可跳 DLsite 原作）。
7. 标签：类别 + 系列胶囊，点 → 对应作品页。
8. 演职员：剧情 / 插画 / 音乐（声优在标题区），点 → 对应作品页。
9. 简介：默认折叠 3 行，「更多」展开，图片随展开出现并可进图集。

原文 / 译文：整页一个开关（默认译文），同时作用于作品标题、曲目名、简介；无译文的项显示原文。翻译操作本身（LLM）在 N6。

### 资源页（2026-09-25，[示意](design/work-files.html)）

1. 导航：每层文件夹单独一页（与 115 浏览页一致），返回逐级退，目录名固定在返回键旁。从详情页「在文件中显示」进入时定位到该层并闪烁提示那一首。
2. 文件夹行写明内容：「24 首 · 字幕 24」「12 张图片」；详情页当前曲目目录打 ✓。
3. 文件夹内首行「播放本文件夹」。点音频：以本文件夹音频为队列从这首开始播，并把该目录设为作品的曲目目录。
4. 按类型点击：音频播放；字幕 → 字幕预览面板；图片 → 全屏图集（本层图片可左右滑）；文本 → 全文预览（识别 UTF-8 / Shift-JIS / GB18030）；视频 → N5。
5. 字幕预览：底部半屏面板（可拉满），时间 + 句子；该曲正在播放时跟随高亮、点句跳转，否则静态并提供「播放这首」；含原文 / 译文与偏移。
6. 已对应音轨的字幕文件照常列出但调淡；音轨行以 💬 标记有字幕。
7. 115 的图片 / 文本在点开时才下载，下载后缓存到本机；列表不加载缩略图，避免批量请求触发风控。

### 视频库与视频播放页（N5，2026-09-25，[示意](design/video.html)）

使用习惯：视频库仅 1 个，视频播放历史 23 条——主要在 115 浏览里直接看、靠历史找回。

1. 视频库（媒体库切「视频」）：顶部「继续观看」横条，取自播放历史中未看完的视频（不论是否入库），16:9 缩略图 + 进度条 + 「剩 x 分钟」，点击从断点续播；下方「视频库」两列 16:9 网格，只放主动加入的视频，长按：重命名、收藏、加入分组、移出视频库；末格虚线「从 115 或文件添加」。
2. 播放页：始终全屏黑底、画面居中（不做 Flutter 竖屏内嵌布局），iOS 26 玻璃控件。顶部：收起、标题、AirPlay、⋯（截取画面设为封面、加入视频库、查看所在文件夹）；中部：快退 / 播放暂停 / 快进；底部：与音频播放页同款粗进度条 + 睡眠定时、倍速、锁定、旋转。3 秒无操作自动隐藏，单击显隐。
3. 手势：横滑微调进度（显示「+0:32 · 28:44」，抬手才 seek，沿用 Flutter）；左 / 右半边双击快退 / 快进；下拉收回迷你播放栏。快进 / 快退按钮与双击都用「设置 → 播放」的同一个步长。
4. 锁定：锁定后屏蔽所有按钮与手势，只留解锁按钮。
5. 续播：打开看过的视频直接从断点开始（看到最后 10 秒内的从头开始），不弹「从头播放」提示。加载期间中间按钮显示转圈且不可点。
6. 后台：继续播放音轨、锁屏控制、迷你播放栏显示 16:9 缩略图；后台暂停超过 10 分钟释放播放器（沿用 Flutter）。
7. 不做视频画中画（不在计划内）。
