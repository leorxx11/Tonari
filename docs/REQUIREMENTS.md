# Tonari 需求与设计

本文写 Tonari 现在做什么、不做什么。排期、实现要点与界面规则见 [PLAN.md](PLAN.md)，界面示意图在 [design/](design/)，用浏览器直接打开。

## 1. 定位

iOS 上的 ASMR / 同人音声播放器，以 DLsite 作品（RJ 编号）为单位组织音视频。音源可以在手机本地，也可以放在 115 网盘或 WebDAV 服务器上；元数据从 DLsite 抓取，标题、简介、曲目名可用自己配置的 LLM 翻译成中文。

## 2. 范围与约束

### 2.1 平台与分发

- iOS 26+，iPhone 优先，竖屏（视频播放页可横屏）。
- 不上架 App Store，自行签名侧载。不做需要额外 entitlement 的扩展：Share Extension、Widget、Action Extension、Live Activity。

### 2.2 技术栈

- **语言 / 界面**：Swift 6 + SwiftUI，UIKit 补位（文件选择、画中画、视频渲染）
- **数据库**：GRDB（SQLite），表结构沿用 Flutter 版 Drift schema 17，原生版新增改动走迁移
- **音频**：AVPlayer + AVAudioSession
- **视频**：mdk-sdk，自写 Swift 封装，外部 Metal 渲染
- **网络 / 解析**：URLSession；HTML 用 SwiftSoup；WebDAV 自写 PROPFIND
- **凭据**：Keychain（115 Cookie、WebDAV 密码、LLM API Key）
- **工程**：纯逻辑放 SPM 包 `TonariCore`，可在 macOS 上 `swift test`

### 2.3 不做

- Android、后端、账号系统、云同步
- 购买 DLsite 作品
- 字幕翻译：R18 对白在主流 LLM 上拒答率高，投入产出不划算，只翻标题、简介、曲目名
- App 内应用锁（用系统的「需要面容 ID」）、备选图标、Spotlight 索引
- 不同音质版本合并成一首：曲目按目录展示，自动选中主目录（见 3.1）

## 3. 功能

### 3.1 资料库与导入

- **导入来源**：文件 App 里选的本地文件夹（security-scoped bookmark）、115 网盘目录、WebDAV 目录。入口在资料库右上角 ＋；在「浏览」Tab 里也能直接导入远程目录。
- **作品识别**：文件夹名含 `RJ` + 6–8 位数字即为一部作品。所选文件夹本身、子文件夹、孙文件夹（如 合集 → 系列 → RJxxx）都会识别，作品内部递归扫描、不限深度。
- **文件分类**按扩展名：音频（wav / mp3 / flac / m4a / ogg / opus / aac）、视频（mp4 / mkv / mov / m4v / webm / ts）、图片、字幕（srt / lrc / vtt / ass / ssa）、文本（txt / md / html）、PDF。
- **快照式导入**：导入时记下文件清单，之后不自动同步。重扫默认跳过已导入的作品，单部作品可在详情页「重新扫描」。
- **移除与删除**：移除作品会留墓碑，重扫不会复活，要找回就重新导入；删除媒体来源会连带删除其下作品。
- **曲目目录**：作品常把同一组曲目按 WAV / MP3、SEあり / なし 分放在多个目录。详情页一次展示一个目录：默认逐层进入音频字节占比超过 60% 的子目录，手动选过的按作品记住。
- **资料库 Tab**：作品、视频、声优、社团、标签等分类入口，收藏分组，最近添加。作品墙有大卡片 / 网格 / 列表三种视图，可按发售日期、销量、评分、收录时间、最近播放、RJ 编号排序，按全部 / 本地 / 远程筛选，也可以随机来一部。
- **收藏分组**：作品和视频都能加入，可新建、重命名、删除分组。
- **搜索 Tab**：没输入时按社团 / 声优 / 标签分类浏览；输入后结果按作品、声优、社团、标签分组；保留最近搜索。

### 3.2 DLsite 元数据

- 入库后在后台逐部补全，每部作品每次启动最多尝试两次；详情页可手动刷新元数据、图片或统计数据，设置里可一次更新全库统计数据。
- **数据来源**：作品页 HTML `https://www.dlsite.com/maniax/work/=/product_id/{RJ}.html`（带 Cookie `adultchecked=1; locale=zh-cn`，解析中文页的作品信息表），加 `product/info/ajax?product_id={RJ}`（评分、销量、价格）。
- **图片**：封面与样品图缓存到 `Documents/images/<RJ>/`，下载时带 `Referer: https://www.dlsite.com/`。主图地址是 `https://img.dlsite.jp/modpub/images2/work/doujin/{bucket}/{RJ}_img_main.jpg`，`bucket` 为 RJ 数字部分向上取整到千位，例如 RJ01560714 → RJ01561000。
- 抓取失败不影响播放。

### 3.3 DLsite 在线

- **发现 Tab**：成人区 / 全年龄区切换，展示排行、新作、特价；列表固定使用账号默认条件：男性向、同人、音声，语言限日文、中文与无语言限制。已入库的作品会标出来。
- **搜索 DLsite**与**在线作品页**：在线作品页和资料库作品页同一布局，但不入库；能听 chobit 试听（逐首播放，不上锁屏）。
- **网页登录**：在 DLsite 自己的登录页登录，App 不接触密码，只保存 Cookie 和登录页 UA，用于读写账号愿望单。
- **待入库**：本地清单，记下以后要入库的作品；资料库里出现同 RJ 作品后标为已入库。

### 3.4 音频播放

- 全局一个播放器；迷你播放栏常驻 Tab 栏上方，全屏播放页仿 Apple Music。
- 后台播放、锁屏 / 控制中心、AirPlay 与蓝牙；电话等中断结束后，若系统允许且不是手动暂停的，自动恢复播放。
- 倍速预设 0.75 / 1 / 1.25 / 1.5 / 2；快进 / 快退步长可设（1–600 秒）。
- 播放模式：顺序、列表循环、单曲循环、随机。
- **睡眠定时**：15 / 30 / 45 / 60 / 90 分钟，或播完 1 / 2 / 3 / 5 首后停；倒计时最后 10 秒淡出，可设为默认播完本曲再停。音频与视频共用。
- **进度**：按曲目记位置，「继续播放」按作品记最后一首；冷启动后迷你播放栏恢复上次内容。
- **主页**：继续收听 / 观看（附睡眠定时快捷项）、随机或按标签挑一部、最近播放、好久没听、最近添加、常听声优。
- **历史与统计**：播放历史分音频和视频；收听统计有总时长、近 30 天，以及最常听的作品、声优、社团。

### 3.5 字幕

- 同目录下 `track.wav.vtt`（DLsite 惯例）或同名不同扩展名的字幕自动关联到曲目；远程字幕在导入时整文件下载解析。
- 文本按 UTF-8 / UTF-16 BOM 读取，失败再按 Shift-JIS 等日文编码解码。
- 播放页像 Apple Music 歌词那样显示：当前行高亮、跟随滚动，点击跳转；迷你播放栏第二行显示当前句。
- **画中画字幕**：把当前句逐帧绘制成视频送进系统画中画窗口，切到别的 App 也能看到字幕。

### 3.6 视频

- mdk-sdk 解码，支持 MKV / HEVC / 10-bit 等 AVPlayer 放不了的格式。
- 来源：作品内的视频、115 / WebDAV 浏览时直接打开、从文件 App 导入；视频库单独展示。
- 播放页始终全屏黑底，控制条 3 秒无操作后隐藏。横屏时横向滑动拖进度、抬手才跳转（对流播友好）；竖屏只用进度条，下滑缩回迷你播放栏。双击左右半屏快退 / 快进。
- 按文件记进度；停在最后 10 秒以内的下次从头播放。后台暂停超过 10 分钟释放播放器。
- 不做竖屏内嵌播放和视频画中画。

### 3.7 云端片库

远程作品与本地作品一样有 RJ 卡片、元数据和曲目列表，远程目录结构按「根目录 → RJ 子目录」处理。

- **115 网盘**：TV 端二维码扫码登录拿 Cookie（115 OpenAPI 已对个人开发者关停）。请求串行、间隔不少于 1.2 秒，子文件夹不预读内容，以免触发风控。播放时把签名直链和请求头（登录 Cookie、防盗链 Cookie、Referer）直接交给播放器，不经本地代理。音频直链在过期前 2 分钟重取，播放中出错或卡住时重取一次。
- **WebDAV**：标准 PROPFIND，只支持 Basic 认证，密码存 Keychain；文件 URL 加 `Authorization` 头直连播放，链接不过期。http 服务器依赖 ATS 例外（`NSAllowsArbitraryLoads`）。
- **播放失败时**对来源做一次探测，连不上或认证失败就点名该服务器，并记入消息。
- **115 离线下载**：作品可「下载到本机」，下载当前曲目目录（音频 + 字幕），用后台 `URLSession`，App 被挂起或退出也能继续；播放与冷启动恢复优先用本地文件。文件存在 `Documents/offline/<RJ>/`，不进备份。

### 3.8 LLM 翻译

- 兼容 OpenAI 协议的服务都能用（DeepSeek、Moonshot、智谱、OpenRouter、Ollama 等），可保存多个，选一个默认；API Key 存 Keychain。
- 详情页「翻译为中文」一次翻译标题、简介和曲目名，结果缓存在数据库里；整页一个原文 / 译文开关，默认显示译文。
- 列表按每批 15 条发送，避免长列表漏翻。

### 3.9 隐私

- 后台模糊（默认开）：离开 App 时盖上模糊层，多任务界面里看不到内容。
- 封面和图片只存 App 沙盒，不申请相册权限；不接入第三方统计或崩溃收集。
- 应用锁交给系统：长按 App 图标 →「需要面容 ID」。

### 3.10 数据与诊断

- **备份与恢复**：导出为一个文件夹，含数据库、图片目录、偏好（`prefs.json`）和 Keychain 凭据（`secrets.json`，明文，需自行妥善保管）。恢复在下次启动时生效。可恢复 Flutter 版备份并自动迁移；原生版备份不能恢复到 Flutter 版。
- **备份提醒**：上次备份超过 30 天时在消息里提醒。侧载签名换证书时数据会丢，备份是唯一的保底。
- **消息**：后台失败（导入、元数据、115 登录失效等）和耗时任务的结果；设置齿轮上显示未读数。
- **存储空间**：仿 iPhone 储存空间页，可清理能重新下载的缓存，管理离线下载。
- **诊断日志**：手动开启的 JSONL 事件日志，可导出反馈问题。
- **崩溃报告**：通过 MetricKit 收集崩溃和卡死诊断，下次启动时写入消息与诊断日志。

### 3.11 快捷指令

App Intents：继续收听、播放作品、随机播放、睡眠定时、打开作品。前三个在后台执行，不拉起 App，可用 Siri 和操作按钮触发。

## 4. 数据

- 表结构定义在 `native/TonariCore/Sources/TonariCore/Database/Schema.swift`：前 17 版逐字沿用 Flutter 版 Drift schema（snake_case 列名、日期存 Unix 秒、字符串列表存 JSON 文本），之后的改动写成迁移。
- 偏好存 UserDefaults，键名沿用 Flutter 版，备份因此能和旧版互通。
- 数据库、图片、离线文件都在 App 的 Documents 目录下。

## 5. 关键技术决策

| 项 | 决策 |
|---|---|
| 实现 | 原生 Swift 6 + SwiftUI（2026-09 起；Flutter 版归档） |
| 数据库 | GRDB，沿用 Flutter 版 Drift schema |
| 音频 / 视频 | AVPlayer / mdk-sdk |
| 云存储 | WebDAV 直连 + 115 Cookie 登录直连；115 OpenAPI、Alist 中间层、本地流播代理都已放弃 |
| 后端 / 同步 | 无后端，纯客户端，不做云同步 |
| LLM 协议 | OpenAI 兼容 |
| 分发 | 自行签名侧载，不上架 |
| 文件导入 | 文件 App 选择，不做 Share Extension |

## 6. 沿革

- 2026-05 起先用 Flutter 实现，完成媒体库、播放器、DLsite 抓取、字幕、简介翻译、隐私、云端片库与视频。
- 2026-09 改为原生重写，逐项对齐 Flutter 版功能后切换为日常使用版本，之后陆续加了发现与愿望单、离线下载、快捷指令、WebDAV 等。阶段记录见 [PLAN.md](PLAN.md)。
- Flutter 版归档在 `flutter` 分支（标签 `flutter-final`），不再维护。
