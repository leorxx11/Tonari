# 使用说明

简体中文 · [English](USAGE.en.md)

## 导入哪个文件夹

在文件 App 里选一个文件夹导入。作品文件夹名里任意位置含 `RJ` + 6–8 位数字即可，大小写不限，例如 `RJ01234567 作品名`、`[サークル名] RJ01234567`。

**单部作品**：直接选作品文件夹。

```text
RJ01234567 作品名/  ← 选它，导入这一部
```

**批量**：选装着多部作品的文件夹，下一层的每个 RJ 文件夹各是一部作品。

```text
音声/  ← 选它，导入 3 部
├── RJ01234567 作品名/
├── RJ01234568 作品名/
└── [サークル名] RJ01234569/
```

**批量，中间隔一层分类**：作品可以放在所选文件夹往下第二层，再深就找不到了。同一层里直接放的作品和分类文件夹可以混用。

```text
音声/  ← 选它，导入 3 部
├── 耳かき/
│   ├── RJ01234567 作品名/
│   └── RJ01234568 作品名/
└── 睡眠導入/
    └── RJ01234569 作品名/
```

115 网盘和 WebDAV 按同样的规则：在「浏览」里进到对应目录，点「导入此文件夹」。已经导入过的作品会跳过，所以往同一个文件夹里加了新作品后再导入一次即可。

## 作品文件夹与字幕

作品文件夹内部结构不限，所有音频、视频、图片、字幕、文本和 PDF 都会递归扫描进来。字幕按下面的规则自动关联到音频：

```text
RJ01234567 作品名/
├── WAV/
│   ├── 01 はじめに.wav
│   ├── 01 はじめに.wav.vtt  ← 关联：音频文件名 + 字幕扩展名（DLsite 惯例）
│   ├── 02 本編.wav
│   └── 02 本編.srt  ← 关联：与音频同名，只换扩展名
├── MP3/  ← 有多个音轨目录时，详情页自动选主目录，可手动切换
│   └── …
└── 字幕/
    └── 01 はじめに.vtt  ← 不关联：和音频不在同一目录
```

- 字幕必须和音频在**同一目录**，名字对上才会关联；支持 srt / lrc / vtt / ass / ssa，编码自动识别 UTF-8、UTF-16、Shift-JIS 和 GB18030。
- 同一首既有 srt / vtt / lrc 又有 ass / ssa 时，用前者。
- 没关联上的字幕仍能在详情页「全部文件」里打开查看。改好文件名或位置后，在详情页 ⋯ 里点「重新扫描此作品」重新关联。

## 备份与换签名

- 备份文件夹里有明文凭据（115 Cookie、WebDAV 密码、LLM API Key），注意保管，不要外传。
- 换签名证书或 Bundle ID 相当于换了一个 App，数据不会带过去：先在旧 App 里导出备份，再到新 App 里恢复。恢复后本地文件夹需要重新导入一次以重新授权。
